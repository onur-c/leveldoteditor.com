Install Link Godot Tools Shortcuts Tutorial

Commands and keyboard shortcuts

No command matches.

Every command the editor registers, grouped like Help → Keyboard Shortcuts, by the kind of work; Keys — means no default key; Mode is the selection mode the command works in (Any: every mode); Where is the menu, or 3D View for the view's own header (View ▾, Overlays ▾, Snap, Checker), — for a command that lives only on a bar, a panel or a window. These are the default keys; Help → Keyboard Shortcuts changes them for one user, and Help → Find Action (Ctrl+K) runs any command by name. 1 / 2 / 3 / 4 (Vertex / Edge / Face / Object Mode) cannot be changed. Camera and mouse gestures (right mouse + WASDQE, Alt + left drag, Shift / Alt + right-click material gestures, double-click selection, Shift + gizmo drag extrude, Ctrl + Shift + gizmo drag Push Through) are in the manual.

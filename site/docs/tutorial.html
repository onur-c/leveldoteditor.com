Install Link Godot Tools Shortcuts Tutorial

Tutorial

Learn Leveldot by building a small game. Part 0 shows the screen and the basic moves. Then six projects build on each other. At the end you can walk through a game in Godot that has coins, a door, a lamp, an alarm and a passage to a second level.

Command and button names are written as they appear in the app. If a step does not work, read the status bar at the bottom of the window: it says why. F1 opens the User Manual.

  • Part 0 (20 min) — Get to know the screen: camera, selection modes, Move / Rotate / Scale, undo, saving
  • Project 1 (30 min) — A room: draw Plane and Box, extruding walls, duplicating, blockout colours
  • Project 2 (45 min) — Two rooms and a corridor: flip Faces, Loop Cut, Extrude, Inset, Bevel, Repeat Last
  • Project 3 (30 min) — Walk around the level: link a Godot game, Export, your own scene, collision
  • Project 4 (40 min) — Coins and a door: entities, reactions, a level signal, "on the 3rd time"
  • Project 5 (60 min) — Pressure plate, lamp, alarm: your own entity types, a flag, a timer, a delay, game code
  • Project 6 (30 min) — A second level: new Level, Player Start, Level Exit, changing levels

You can stop after Project 2 if you do not use Godot: Projects 1 and 2 need only Leveldot.

Preparation

You need: Leveldot, and from Project 3 on Godot 4.4 or later. A numpad helps with texture settings but is not required.

Make one folder for everything:

Documents\Leveldot Tutorial\
   levels\     your Leveldot projects
   game\       the Godot project (made in Project 3)

Create the levels folder now.

Part 0: First steps

What Leveldot does

You build level geometry (rooms, corridors, stairs), place entities (doors, coins, lamps) and write the level's logic as "when this happens, do that". Then you send the level to Godot:

Leveldot project  --Export (Ctrl+E)-->  your Godot game
geometry, entities, logic               a level scene, built by the Leveldot Bridge addon

The addon builds a level scene from each export. You put that scene into a scene of your own. When you export again, the level scene updates by itself; your own scene and scripts stay as they were.

Opening it

Run LeveldotEditor.exe. A new project opens with a selected 2 m Cube and a New level card. Click an empty spot in the 3D view to close the card.

The screen

  • Menus (very top) — File, Edit, Select, Mesh, Texture, Create, Window, Help. Modelling tools are in Mesh; panels and windows (Level Logic, Logic Graph, Recovery…) are in Window
  • Toolbar (below the menus) — Undo / Redo, the project name, Modeling / Logic, W E R, Play, Export
  • Selection bar (second row) — Selection icons that stay in the same place in every mode; unavailable ones are grey
  • Blockout bar (third row) — Drawing tools, Height and Draw on
  • Tools (left column) — 1 2 3 4 (selection modes) and the edit and modify commands; More tools holds the rest
  • 3D view (centre) — Where you build. Its header has View, Snap, the grid step, Checker and Overlays
  • Outliner (top right) — Every object, the level picker, search, Show and Lock columns
  • Details (bottom right) — The selection's name, Position, Rotation, Size, entity properties and events
  • Status bar (very bottom) — Entities and Props drawers, a hint for what you can do now, the selection and the result of the last action. When nothing happens, look here first

The camera

  • Hold the right mouse button and move — Look around
  • W A S D with the right button held — Fly; Q / E down / up; Shift faster
  • Middle mouse drag — Pan
  • Alt + left mouse drag — Orbit the selection
  • Wheel — Zoom
  • F — Frame the selection (everything when nothing is selected)
  • Alt+T / Alt+F / Alt+S / Alt+P — Top / Front / Side / Perspective

Lost? Click the cube and press F.

Modes and tools

Two questions: what do I select (the mode), and what do I do with it (the tool).

  • Modes (fixed keys): 1 Vertex, 2 Edge, 3 Face, 4 Object.
  • Tools: W Move, E Rotate, R Scale. The handles are red (X), green (Y, up) and blue (Z).

Try it:

  1. Press 4, click the cube, press W and drag the red arrow. It moves in 1 m steps because Snap is on and the grid step is 1 m.
  2. Press E and drag the green ring: 15° steps.
  3. Press R and drag a handle; with Shift held all three axes scale together.
  4. Press 3, click the top face and pull the green arrow up with W. Only that face moves.
  5. Move an edge (2) and a vertex (1) too.
  6. Press Ctrl+Z until everything is undone. Ctrl+Y redoes.

Grab (G) moves the selection with the mouse. Press X / Y / Z to lock an axis and type a number: G, Y, 2, Enter moves it 2 m up. Click or Enter confirms, Esc cancels. Many tools work this way: key, axis, number, Enter.

Finding a command

  • Ctrl+K opens Find Action: type a few letters (bevel, export) to see the command, its key and when it works.
  • Right-click without moving in the 3D view opens the command menu of the current mode.

Saving

A project is a folder, name.leveldot, with a project.json inside. Ctrl+S saves (the first time it asks for a folder). Ctrl+Shift+S saves a copy. Textures and export need a saved project. After a crash, Recovery Snapshots offers the last copy (made every 30 seconds) at the next start.

Warm-up over: File → New Project (Ctrl+N), and choose Don't Save if asked.

Project 1: The first room

Goal: an 8 × 8 m room without a ceiling, with a few crates and a table, in colour.

1. Save. File → Save As… → Documents\Leveldot Tutorial\levels → folder name tutorial_1.leveldot.

2. The floor. Select the cube and press Delete. Press Shift+P (Draw Plane) and drag an 8 × 8 cell area on the grid; the floor snaps to the grid. Esc ends the tool.

3. Walls. Pull the floor's outer edges up:

  1. With the floor selected, press 2 (Edge Mode). Open edges show as an orange dashed line.
  2. Ctrl+A selects all four.
  3. Shift+E (Extrude), Y, type 3, Enter.

The walls rise 3 m and face inward. From outside the near walls show as see-through blue stripes: those are the backs of the faces, and a click goes through them to what is behind. Overlays → Back Faces (Alt+Shift+B) turns the stripes off; then the near walls are simply not drawn.

4. A crate. Press 4, then Shift+B (Draw Box). Drag a 1 × 1 cell base on the floor, click to set the height (one grid step), then Esc.

5. Duplicating. With the crate selected: - Ctrl+D copies it in place; move it with G, X, 2, Enter. - Shift+D copies it and sticks it to the mouse; click to drop.

Scatter four or five crates. To stack one, select it and press G, Y, 1, Enter.

6. A table. Set Height in the Blockout bar to Custom… and type 0.8. Draw a 2 × 1 cell box. Set Height back to Grid (Auto).

7. Scale and rotate. Select a crate; press R and shrink it, press E and turn it 45°.

8. Colours. Alt+Shift+1…9 pick ready-made flat colours (1 grey, 2 light, 3 dark, 4 orange, 5 red, 6 green, 7 blue, 8 yellow, 9 purple); Shift+T applies the active one to the selection. - Crates: select them with Shift+click in Object Mode, Alt+Shift+4, Shift+T. - Floor: the floor and walls are one object. Press 3, click the floor face, Alt+Shift+3, Shift+T. - Walls: in Face Mode press Ctrl+A, Shift+click the floor to remove it, Alt+Shift+2, Shift+T.

9. Names. Select an object's row in the Outliner and press F2: Room, Crate 1…

10. Hide and lock. Press H to hide the selection, Alt+H to show everything. Click the lock in the Outliner's Lock column next to Room: it can no longer be selected by clicking, so you cannot move it by accident. Unlock it again.

11. Save with Ctrl+S.

You should see

a room with a dark floor and light walls, open at the top, with orange crates and a table, and no red message in the status bar.

Try it yourself

  • Overlays → Edge Lengths (Alt+Shift+L) shows edge lengths in metres.
  • Nudge a crate with Alt + arrow keys.
  • Press [ and ] to change the grid to 0.5 m and 2 m and draw a crate: what changes?

Project 2: Two rooms joined by a corridor

Goal: room A, a 4 m corridor and room B, all one mesh, with a wall niche, a bevelled column and a tower.

You will learn: Flip Faces, Loop Cut, axis-locked Extrude, Inset, Bevel, Repeat Last.

In a room the faces point inward, so from outside the nearest wall cannot be selected: it is drawn as blue stripes (or not at all, with Overlays → Back Faces off) and a click goes through it. To select a wall, look at it from the opposite side or fly into the room.

1. New project. File → New Project, then Save As… → levels\tutorial_2.leveldot.

2. Room A. Select the cube (4, click). In Details set Position 0, 0, 0 (the centre of the base) and Size W 6, H 3, D 6. Press Shift+N (Flip Faces): the box is now a room seen from inside.

The Size fields work only on boxes that have not been cut or flipped yet: set the size first.

3. A doorway (Loop Cut). The +X wall needs a part 2 m wide and 2.5 m tall. 1. With the room selected press Ctrl+R (Loop Cut). 2. Move the mouse over an edge that runs along Z, for example where the +X wall meets the floor. The ring is drawn in the view. 3. Turn the mouse wheel to 2 cuts and click. The wall is cut at z = −1 and z = +1. 4. Press [ for a 0.5 m grid. Press Ctrl+R, hover a vertical corner edge, put the cut one cell below the ceiling and click: a cut at 2.5 m.

The wall now has six parts; the lower middle one (2 × 2.5 m) is the doorway.

4. The corridor. 1. Press 3 and then Esc (so the handle is not in the way). Look at the +X wall from inside and click the lower middle part. 2. Shift+E, X, 4, Enter. The part moves 4 m outward and leaves a corridor, with walls, floor and ceiling made automatically.

5. Room B. 1. The corridor's end face is still selected: Shift+E, X, 6, Enter. 2. Select the −Z side wall of that last section, Shift+E, Z, -2, Enter. Then the +Z side wall, Shift+E, Z, 2, Enter.

Room B is 6 × 6 m and 2.5 m tall.

6. A niche (Inset + Extrude). Select the lower part of room A's −Z wall. I, 0.75, Enter: a frame opens inside the wall. Shift+E, Z, -0.5, Enter pushes the middle face out.

7. A bevelled column. Press 4 and draw a small box in room B. In Details: Size 0.6, 2.5, 0.6, Position 11.5, 0, -1.5. Press 2, click a vertical edge, press X (edge ring) to select all four, then B, 0.15, Enter: the column becomes an octagon.

8. A tower with Repeat Last. Draw a 2 × 2 m box in a corner of room B. Press 3, select its top face, Shift+E, Y, 0.5, Enter, then Shift+R twice. Each Shift+R repeats the last extrude.

9. Colours. Room A floor dark (3), walls light (2), room B blue (7), column and tower orange (4). In Face Mode a double-click selects the connected faces; Shift + double-click only those on the same plane.

10. Save (Ctrl+S).

You should see

From above (Alt+T): room A, a corridor and room B, with a niche in A's back wall, an octagonal column and a stepped tower in B.

If you get stuck

  • The corridor grew inward and the walls overlap — Ctrl+Z, then flip the sign of the number
  • I click one wall and another is selected — The near wall is only a back face (blue stripes): look from the opposite side
  • A click on a face does not change the selection — You clicked the handle: press Esc or click elsewhere on the face
  • Loop Cut does not go where I want — The ring runs perpendicular to the edge under the mouse: hover another edge
  • The Size fields do nothing — The object was cut or flipped: use Ctrl+Z or scale with R

Try it yourself

  • Press 4, draw a new box and press Ctrl+Shift+W (Hollow): a room with walls 0.25 m thick. In Face Mode select a wall from inside and press Ctrl+Shift+O (Opening); set From floor to 0 on its card for a doorway.
  • Draw a line across a wall with C (Cut) in the Front view (Alt+F).

Project 3: Walking around the level (Godot)

Goal: send the level to Godot and walk around in it. Then change something in Leveldot and see it arrive with one key.

1. The Godot project. In Godot's Project Manager choose Create: name Leveldot Tutorial Game, folder Documents\Leveldot Tutorial\game, renderer Forward+. Create & Edit.

2. Link the game. With tutorial_2 open in Leveldot, choose File → Link Godot Project… and pick Documents\Leveldot Tutorial\game (the folder with project.godot). Leveldot installs and enables the Leveldot Bridge addon, chooses the export folder and exports. A summary tells you what was done. (Help → Link a Godot Project… has the details.)

3. Load the addon. In Godot choose Project → Reload Current Project. A Leveldot button now sits at the top, beside 2D / 3D / Script. Press it: on the Levels page tutorial_2 shows a green mark (Up to date). If something goes wrong, the reason is written here.

4. The player. In Godot's FileSystem panel right-click res:// → Create New → Script…, name it player.gd, Create, and replace its content with this walker (WASD, mouse, Space jumps, Esc releases the mouse):

extends CharacterBody3D
## A small first-person walker. It is in the group "player" on physics layer 1:
## that is what the Coin entity looks for.
const SPEED := 4.5
const JUMP := 4.5
const LOOK := 0.0025
var camera := Camera3D.new()
var _settle := 0.0  # seconds after the mouse was captured during which its motion is ignored

func _ready() -> void:
    add_to_group("player")
    var shape := CapsuleShape3D.new()
    shape.radius = 0.3
    shape.height = 1.7
    var collider := CollisionShape3D.new()
    collider.shape = shape
    collider.position.y = 0.85
    add_child(collider)
    camera.position.y = 1.6
    add_child(camera)
    camera.current = true
    if DisplayServer.get_name() != "headless":
        _capture()

## Capturing the mouse warps it to the window centre, which arrives as one
## large motion: the view must not jump because of it.
func _capture() -> void:
    Input.mouse_mode = Input.MOUSE_MODE_CAPTURED
    _settle = 0.25

func _unhandled_input(event: InputEvent) -> void:
    if event is InputEventMouseMotion and Input.mouse_mode == Input.MOUSE_MODE_CAPTURED and _settle <= 0.0:
        rotation.y -= event.relative.x * LOOK
        camera.rotation.x = clampf(camera.rotation.x - event.relative.y * LOOK, -1.4, 1.4)
    elif event is InputEventKey and event.pressed and event.keycode == KEY_ESCAPE:
        Input.mouse_mode = Input.MOUSE_MODE_VISIBLE
    elif event is InputEventMouseButton and event.pressed and Input.mouse_mode != Input.MOUSE_MODE_CAPTURED:
        _capture()

func _physics_process(delta: float) -> void:
    _settle = maxf(_settle - delta, 0.0)
    var move := Vector2(
        float(Input.is_physical_key_pressed(KEY_D)) - float(Input.is_physical_key_pressed(KEY_A)),
        float(Input.is_physical_key_pressed(KEY_S)) - float(Input.is_physical_key_pressed(KEY_W)))
    if move.length() > 1.0:
        move = move.normalized()
    var direction := transform.basis * Vector3(move.x, 0, move.y)
    velocity.x = direction.x * SPEED
    velocity.z = direction.z * SPEED
    if is_on_floor():
        velocity.y = JUMP if Input.is_physical_key_pressed(KEY_SPACE) else 0.0
    else:
        velocity.y -= 12.0 * delta
    move_and_slide()

5. Your game scene. On the Leveldot screen → Levels, select tutorial_2 and press Create Game Scene…. Accept the suggested file name (res://leveldot/levels/tutorial_2.tscn). The scene opens: it holds the level as a child called World. Now: 1. Select the scene's root node, Add Child Node (Ctrl+A) → CharacterBody3D, name it Player. Drag player.gd from the FileSystem onto it. In the Inspector set Transform → Position to 0, 0.1, 0 (the middle of room A). 2. In the 3D view's top bar open the ⋮ menu and choose Add Sun to Scene and Add Environment to Scene. 3. Ctrl+S.

A warning about a missing collision shape on Player can be ignored: the script adds its own capsule and camera.

6. Play. Press F6: it runs the scene that is open in the editor, here tutorial_2. Walk from room A through the corridor to room B.

Why do you not walk through walls? Every object's Details → Collision is Generated Static by default: the game gets a solid collider for it. Set an object to None to walk through it.

7. Change and see. In Leveldot add a crate to room A and press Ctrl+E. Switch to Godot: within a few seconds a message says the level was refreshed, and the open scene shows the crate. Press F6. You do not need to save first: Export saves for you.

If your game scene has unsaved changes, Godot leaves it alone and says so. Save it (Ctrl+S), then Scene → Reload Saved Scene.

You should see

you start in the middle of room A, the walls stop you, and you can walk through the corridor to room B. It may be dark: the ceilings block the sun. Project 5 adds a lamp.

If you get stuck

  • No Leveldot button, or no level scene — Project → Reload Current Project; check that Leveldot Bridge is on under Project Settings → Plugins
  • I fall through the floor — Set Player's Position to 0, 0.1, 0
  • An error code (A201, X402…) — See the common problems in Help → Link a Godot Project…

Try it yourself

set the tower's Collision to None, export and walk through it. Paint room B's walls another colour and export.

Project 4: Coins and a door

Goal: a door closes the corridor. Collecting the three coins in room A opens it, and Godot's Output panel counts the coins.

You will learn: making entity types, placing entities, reactions, a level signal, "on the Nth time", Level Start, the log.

Three ideas first

  • An entity is an object in the level that does something in the game: a coin, a door, a lamp. You make entity types in Godot as scripts. A script's signal collected becomes an event the entity announces in Leveldot; its func open() becomes an action it performs.
  • A reaction is the only building block of logic: "when this happens → do that". It belongs to an entity's event (Entity Details → Events) or to the level (Window → Level Logic…).
  • A signal is a name for the level, such as "Coin collected". All coins raise the same signal; you write what happens once, on the signal.

Make the entity types in Godot

1. Coin. On the Leveldot screen choose Entities → New Entity…. Name Coin, Starts as Empty, Create. Godot writes res://leveldot/entities/coin.gd and coin.tscn. Open coin.gd and replace its content with:

extends LeveldotEntity
## A coin the player collects by walking into it.

## Raised once, when the player walks into the coin.
signal collected

## Turns per second, in radians.
@export var spin_speed := 2.5

const LEVELDOT_EDITOR_SIZE := Vector3(0.4, 0.4, 0.4)

var _done := false
var _visual := MeshInstance3D.new()


func _ready() -> void:
    var area := Area3D.new()
    var collider := CollisionShape3D.new()
    collider.shape = SphereShape3D.new()
    collider.position.y = 0.9
    area.add_child(collider)
    area.collision_layer = 0
    area.collision_mask = 1
    area.body_entered.connect(_on_body_entered)
    add_child(area)
    var disc := CylinderMesh.new()
    disc.top_radius = 0.28
    disc.bottom_radius = 0.28
    disc.height = 0.06
    _visual.mesh = disc
    _visual.position.y = 0.9
    _visual.rotation.x = PI / 2
    add_child(_visual)


func _process(delta: float) -> void:
    _visual.rotation.y += spin_speed * delta


func _on_body_entered(body: Node3D) -> void:
    if _done or not body.is_in_group("player"):
        return
    _done = true
    _visual.visible = false
    collected.emit()

Save with Ctrl+S. The coin only reacts to bodies in the player group, which player.gd joins.

2. Door. The same way: New Entity…, name Door, Empty, Create. Replace door.gd with:

extends LeveldotEntity
## A slab that blocks the way until it is opened; it slides up.

## Raised when the door has finished opening.
signal opened

## Slab travel per second, as a fraction of its height.
@export var open_speed := 1.5

const LEVELDOT_EDITOR_SIZE := Vector3(1.2, 2.2, 0.16)

var _amount := 0.0
var _target := 0.0
var _body := AnimatableBody3D.new()


func _ready() -> void:
    var collider := CollisionShape3D.new()
    var shape := BoxShape3D.new()
    shape.size = LEVELDOT_EDITOR_SIZE
    collider.shape = shape
    collider.position.y = LEVELDOT_EDITOR_SIZE.y * 0.5
    _body.add_child(collider)
    var mesh := MeshInstance3D.new()
    var box := BoxMesh.new()
    box.size = LEVELDOT_EDITOR_SIZE
    mesh.mesh = box
    mesh.position.y = LEVELDOT_EDITOR_SIZE.y * 0.5
    _body.add_child(mesh)
    add_child(_body)


func _physics_process(delta: float) -> void:
    var before := _amount
    _amount = move_toward(_amount, _target, delta * maxf(open_speed, 0.1))
    _body.position.y = (LEVELDOT_EDITOR_SIZE.y + 0.05) * _amount
    if before < 1.0 and _amount == 1.0:
        opened.emit()


## Slides the door open.
func open() -> void:
    _target = 1.0

Save. Godot writes the game's entity types to a file by itself when a script or scene is saved; when you switch back to Leveldot, it reads them.

Place them in the level

3. The types. In Leveldot press Entities in the status bar (or Shift+A). The Entities drawer should list Coin and Door. If not, switch to Godot and back, or use Entity Catalog… (Ctrl+Shift+A) → Import from Godot…. If the file was not written, press Write Types File on the Leveldot screen's Entities page in Godot first, then in Leveldot Import from Godot… and pick res://leveldot/generated/entity_types.json in your game folder.

4. The door. Drag Door onto the corridor floor. In Details set Position 5, 0, 0 and Rotation 0, 90, 0 (it now closes the corridor). Name it Door (F2).

5. The first coin. Drag Coin onto room A's floor: Position -2, 0, 2, name Coin 1. In Details press Entity Details…, open the Events tab, find collected and press Add action. Set Do = Raise a signal, Signal = New signal…, Name = Coin collected, Apply.

The coin now tells the level "Coin collected". It does not know about the door.

6. The other coins. Select Coin 1 and press Ctrl+D twice (copies keep their reactions). Positions -2, 0, -2 and 2, 0, -2; names Coin 2, Coin 3.

7. Open the door on the third coin. Window → Level Logic… (Ctrl+L). Select the signal Coin collected. Under When it is raised press Add reaction: - Do = Tell an entity, Entity = Door, Performs = open, When = On the N-th time, once, N = 3, Apply. - Add another: Do = Write to the log, Message = Coins: {count}/3, When = Every time, Apply.

8. Level start. In the same window choose Level start → Add reaction → Write to the log: Collect three coins to open the door. Apply, Close.

9. When the door opens. Select Door; in Events, under opened, Add action → Write to the log: Door opened!

10. Check it. - With Door selected, Reacts to in Events shows what opens it. - Window → All Reactions… lists every reaction in the level. - Window → Logic Graph… draws the connections of the selection, or the whole level with Whole Level. It only shows; nothing is changed there. - Selecting a coin shows a dashed arrow to the door in the 3D view.

11. Play. Ctrl+E, switch to Godot. New Entity… opened the scenes of Coin and Door in their own tabs, and F6 runs the open one: click the tutorial_2 tab first (or double-click tutorial_2.tscn in FileSystem), then press F6. Keep the Output panel open.

You should see

In Output: Collect three coins to open the door., then Coins: 1/3, Coins: 2/3, Coins: 3/3. On the third the door slides up and Door opened! appears. You can pass through the corridor.

If you get stuck

  • The drawer shows no Coin or Door — Are the files in res://leveldot/entities? Check the Leveldot screen → Entities page: a yellow or red note says what was left out. Press Write Types File there, then in Leveldot Entity Catalog… → Import from Godot… and choose entity_types.json in the game's leveldot/generated folder
  • I touch a coin and nothing happens — In Godot turn on Project Settings → Leveldot Bridge → Debug → Log Events: every reaction that runs is printed. No line at all means the coin never fired: is Player in the player group (does it have player.gd)?
  • The door is turned the wrong way — Change Rotation Y between 0 and 90
  • E301 in Godot — A placed entity has no scene in the game. Keep every entity's .tscn in res://leveldot/entities

Try it yourself

  • Entity Details… → Properties of the door: set open_speed to 0.3. A changed value is coloured; the arrow beside it restores the default.
  • Put two more coins in room B and use Every N-th time (N = 2) to log every second coin.

Project 5: A pressure plate, lamps and an alarm

Goal: a plate in room B turns the room lamp on while you stand on it (and off again 3 seconds after you leave it). The third coin starts a blinking red alarm lamp. Stepping on the plate during the alarm ends the level, and game code shows "Congratulations".

You will learn: more entity types, an entity's properties, After (delay), a flag, Only while, a timer, game code listening to the level.

An entity script is read like this:

  • signal pressed — Announces: an event the entity raises
  • func turn_on() -> void: — Performs: an action it can do
  • @export var energy := 3.0 — a property (Entity Details → Properties)
  • ## description lines — the description of the type, event or property
  • const LEVELDOT_EDITOR_SIZE := Vector3(...) — the size of the box drawn in Leveldot

Functions that start with _ are private. In Godot, the Leveldot screen → Entities page shows what was read from each script.

The built-in entities (Signal, Counter, Timer, Light, Trigger Area, Mover and the others) are written the same way: each is a short, readable script in the addon's runtime/entities folder (effects in runtime/effects, Level Exit and Player Start in runtime/levels). Open one next to your own when you want to see how something is done; godot-addon/README.md lists what each one shows.

Part A: Two more entity types

1. The pressure plate. Entities → New Entity…, name Pressure Plate, Empty, Create. Replace pressure_plate.gd with:

extends LeveldotEntity
## A plate on the floor. It is pressed while the player stands on it.

## The player stepped onto the plate.
signal pressed
## The player has been off the plate for hold_time seconds.
signal released

## Seconds the plate stays "on" after the player steps off. Stepping back on in time keeps it on.
@export var hold_time := 3.0

const LEVELDOT_EDITOR_SIZE := Vector3(1.0, 0.1, 1.0)

var _top := MeshInstance3D.new()
var _release_in := -1.0  # seconds until released is raised; below 0 = not waiting


func _ready() -> void:
    var area := Area3D.new()
    var shape := BoxShape3D.new()
    shape.size = Vector3(1.0, 0.6, 1.0)
    var collider := CollisionShape3D.new()
    collider.shape = shape
    collider.position.y = 0.3
    area.add_child(collider)
    area.collision_layer = 0
    area.collision_mask = 1
    area.body_entered.connect(_on_body_entered)
    area.body_exited.connect(_on_body_exited)
    add_child(area)
    var slab := BoxMesh.new()
    slab.size = Vector3(1.0, 0.1, 1.0)
    _top.mesh = slab
    _top.position.y = 0.05
    var paint := StandardMaterial3D.new()
    paint.albedo_color = Color(0.2, 0.55, 0.95)
    _top.material_override = paint
    add_child(_top)


func _process(delta: float) -> void:
    if _release_in < 0.0:
        return
    _release_in -= delta
    if _release_in <= 0.0:
        _release_in = -1.0
        released.emit()


func _on_body_entered(body: Node3D) -> void:
    if body.is_in_group("player"):
        _release_in = -1.0
        _top.position.y = 0.02
        pressed.emit()


func _on_body_exited(body: Node3D) -> void:
    if body.is_in_group("player"):
        _release_in = maxf(hold_time, 0.0)
        _top.position.y = 0.05

2. The lamp. New Entity…, name Lamp, Empty, Create. Replace lamp.gd with:

extends LeveldotEntity
## A lamp that lights the room around it.

## The lamp was turned on.
signal turned_on
## The lamp was turned off.
signal turned_off

## Colour of the light.
@export var color := Color(1.0, 0.85, 0.6)
## Brightness of the light.
@export_range(0.0, 16.0) var energy := 3.0
## Lit when the level starts.
@export var starts_on := false

const LEVELDOT_EDITOR_SIZE := Vector3(0.4, 0.4, 0.4)

var is_on := false
var _light := OmniLight3D.new()
var _bulb := StandardMaterial3D.new()


func _ready() -> void:
    _light.light_color = color
    _light.omni_range = 8.0
    _light.shadow_enabled = true
    _light.position.y = 0.2
    add_child(_light)
    var sphere := SphereMesh.new()
    sphere.radius = 0.15
    sphere.height = 0.3
    var bulb := MeshInstance3D.new()
    bulb.mesh = sphere
    bulb.position.y = 0.2
    _bulb.emission_enabled = true
    _bulb.emission = color
    bulb.material_override = _bulb
    add_child(bulb)
    _show(starts_on)


## Turns the lamp on.
func turn_on() -> void:
    if not is_on:
        _show(true)
        turned_on.emit()


## Turns the lamp off.
func turn_off() -> void:
    if is_on:
        _show(false)
        turned_off.emit()


## On when it is off, off when it is on.
func toggle() -> void:
    if is_on:
        turn_off()
    else:
        turn_on()


func _show(on: bool) -> void:
    is_on = on
    _light.light_energy = energy if on else 0.0
    _bulb.albedo_color = color if on else Color(0.2, 0.2, 0.2)
    _bulb.emission_energy_multiplier = 2.0 if on else 0.0

Save both. In Leveldot the Entities drawer now has Lamp and Pressure Plate (if not, Entity Catalog… → Update from Godot, or Write Types File in Godot first). Click the Lamp tile to see its properties (color, energy, starts_on), what it performs (toggle, turn_off, turn_on) and what it announces (turned_off, turned_on). A changed script updates in Leveldot when you save it.

Part B: Place them

3. Drag Pressure Plate onto room B's floor: Position 10, 0, 0, name Plate. 4. Drag Lamp: Position 10, 2, 0, name Room Lamp; leave starts_on off. 5. Select Room Lamp, Ctrl+D: Position 12, 2, 2, name Alarm Lamp. In Entity Details… → Properties pick a red color and set energy 6.

Part C: The logic

6. Plate → lamp. Press Logic in the toolbar (or F4): the level turns grey and clicking selects only entities. - Select Plate, press K (Connect), then click Room Lamp. In the form set When it announces = pressed, Performs = turn_on, Apply. - K again, Room Lamp: released → turn_off, Apply. The plate itself raises released only when you have been off it for its hold_time (3 seconds), so stepping back on in time keeps the lamp lit.

Hover an arrow to read its reactions as sentences. Press F4 to return to modelling.

7. The alarm flag. Window → Level Logic… → Flags → New flag: name Alarm, Create flag. A flag is an on / off value of the level, off at the start.

8. The third coin sets the alarm. Signals → Coin collected → Add reaction: Do = Set a flag, Flag = Alarm, Set to = On, When = On the N-th time, once, N = 3, Apply. The door reaction from Project 4 still runs: an event can have any number of reactions.

9. The lamp blinks. Timers → Add timer: Every 0.5 s, Do = Tell an entity, Alarm Lamp, toggle, Only while = Alarm is on, Apply.

10. The plate ends the level. Close, select Plate, event pressed → Add action: Do = Raise a signal, Signal = New signal… Level finished, Only while = Alarm is on, Apply.

11. When the level finishes. Window → Level Logic… → Signals → Level finished, three reactions: - Set a flag: Alarm → Off. - Tell an entity: Alarm Lamp → turn_off, press More… and set After = 0.6, Apply. After delays a reaction by that many seconds; here it makes the turn_off come after the timer's last tick. - Write to the log: Level finished!

12. Ctrl+E.

Part D: Game code listens

Game code meets the level at named signals. The Leveldot_Signals node inside the level scene raises raised(signal_name) whenever one of the level's signals is raised.

13. In Godot, open your game scene, right-click its root node → Attach Script → Create, and use this content:

extends Node3D
## Shows a message when the level raises "Level finished".


func _ready() -> void:
    var signals := find_child("Leveldot_Signals", true, false)
    signals.raised.connect(_on_level_signal)


func _on_level_signal(signal_name: String) -> void:
    if signal_name == "Level finished":
        var layer := CanvasLayer.new()
        var label := Label.new()
        label.text = "Congratulations! Level complete."
        label.position = Vector2(40, 40)
        label.add_theme_font_size_override("font_size", 40)
        layer.add_child(label)
        add_child(layer)

Save, then F6.

Every level signal is also a real Godot signal on Leveldot_Signals ("Level finished" → level_finished). raise("Name") raises one from code; get_flag("Alarm") and set_flag("Alarm", true) read and write a flag. In Level Logic, the In game code section of a signal or flag shows these lines ready to copy.

You should see

  1. Room B is dark; stepping on the plate lights the room lamp, stepping off turns it off 3 seconds later, unless you step back on within those 3 seconds.
  2. The third coin opens the door and starts the red lamp blinking.
  3. Stepping on the plate during the alarm stops the lamp, logs Level finished! and shows Congratulations! Level complete.
  4. Stepping on the plate before the alarm does not finish the level: its Only while condition is not met.

If you get stuck

  • Lamp or Pressure Plate is missing in Leveldot — Does the script say extends LeveldotEntity and is the scene in res://leveldot/entities? The Leveldot screen → Entities page lists what was read
  • A function is missing from Performs — Names starting with _ are private; a parameter must be a single typed one (bool, int, float, String, Vector3)
  • The lamp never lights — Turn on Log Events (Project 4): does a Plate · pressed line appear? If not, the plate is not on the floor (Position Y = 0)
  • No "Congratulations" but the log line appears — Is the script attached to the root node of your game scene? Look for an error in Output

Try it yourself

  • Add func set_energy(value: float) -> void: with a ## Sets the brightness. line to lamp.gd, then use the Value field of a reaction that performs it.
  • Select Plate → Entity Details… → Properties and change hold_time to 1: the property comes from @export var hold_time in pressure_plate.gd.
  • Add @export var one_shot := false to pressure_plate.gd: the property appears in Leveldot by itself.

Project 6: A second level, the Cellar

Goal: a passage in room B leads to a second level, the Cellar; a passage in the Cellar leads back to room A. Both levels are in the same project and the same game.

You will learn: New Level, Player Start, Level Exit and its destination, Open Level.

  • A project holds several levels. The level picker at the top of the Outliner opens them and holds commands such as New Level and Rename Level…. Each level has its own objects and logic; materials and entity types are shared. One level knows another only through an exit's destination.
  • Player Start is where the player appears. Level Exit is a box that takes the player to another level. Both are built in (category Level in the Entities drawer): you do not make them in Godot.

1. A start in room A. Open tutorial_2. Press Shift+A, type level in the search, and drag Player Start onto room A's floor. Position 0, 0, 0; rotate it with E so the arrow points into the corridor (+X); name it Entry. Ctrl+S. With one Player Start in a level, the game puts the player there (the node in the player group).

2. The Cellar. 1. Level picker → New Level. An empty level opens. Level picker → Rename Level…, type Cellar, Enter. 2. Create → Quick Box at View Centre. Position 0, 0, 0, Size 8, 3, 8, Shift+N to make it a room. Give it a blockout colour so you can tell it from room A.

Ctrl+PageUp / Ctrl+PageDown switch between levels.

3. The Cellar's start and exit. 1. Shift+A, level: drop Player Start: Position -2, 0, 0, arrow facing +X, name Stairs. 2. Drop Level Exit: Position 3.4, 0, 0, Rotation 0, 90, 0, name Up. It is a purple box; invisible in the game, it works when the player walks into it. 3. With Up selected: Entity Details… → Properties → Destination. In the top list choose tutorial_2; the lower list holds its Player Starts: Default start (Entry) is fine. 4. Ctrl+S saves both levels.

4. The passage in room B. Ctrl+PageUp opens tutorial_2. Drop a Level Exit at Position 12.4, 0, 0, Rotation 0, 90, 0, name To Cellar. In Entity Details… → Properties → Destination pick Cellar and Stairs. Press Open Level below the lists to check where the player will arrive: the Cellar opens with Stairs selected.

5. Export. Ctrl+E exports both levels, each into its own folder.

6. Play. In Godot click the tutorial_2 tab (the game scene) and press F6. Open the door with the coins, go to room B and walk into the passage by the back wall.

You should see

the game starts in room A at Entry. Walking into the passage fades out and puts you in the Cellar at Stairs. Walking into the Cellar's exit returns you to room A at Entry, with the coins and the door as at the start. (The Cellar has no game scene of its own, so on the way in the game swaps the level inside your scene and your player, camera and lights stay. Room A has one, tutorial_2, so on the way back the game loads that scene again and builds player, camera and lights anew.)

If you get stuck

  • Cellar is not in the Destination list — Are both levels in the same project? The level picker lists them
  • No Open Level button — A destination level must be chosen
  • I walk into the passage and nothing happens — Read Godot's Output: it says why (for example the Cellar was not exported). Check the exit's Enabled and On Touch boxes
  • Wrong facing in the Cellar — Rotate Stairs with E and export again
  • A yellow line below the lists — The destination has a problem; the text says which. Window → Validation Issues… (F8) lists all problems

Try it yourself

  • Turn off On Touch for To Cellar and add a reaction on Coin collected: Tell an entity To Cellar → go, On the N-th time, once, 3. The third coin sends the player to the Cellar.
  • In the Cellar, Level Logic → Level start → Add reaction → Go to a level: tutorial_2, After = 5.
